# 支援範圍 / Support

## 中文版

預覽版支援一般 Linux x86_64、Node.js 22／24 與 Docker Compose 自架路徑。可重現 bug、文件錯誤與相容性問題可在 issue 回報；漏洞改走 [SECURITY.md](../SECURITY.md)。OMP／Harness／ACS、外部 Task Adapter、非 Linux 平台、託管環境與大規模多租戶屬實驗或未承諾範圍。

## English version

The preview supports the documented Linux x86_64, Node.js 22/24, and Docker Compose path. File reproducible bugs and documentation or compatibility issues as public issues; use [SECURITY.md](../SECURITY.md) for vulnerabilities. OMP/Harness/ACS, external task adapters, non-Linux platforms, hosted environments, and large multi-tenant deployments are experimental or unsupported.
