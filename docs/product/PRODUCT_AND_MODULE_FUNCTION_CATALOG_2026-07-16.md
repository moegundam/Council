# 公開模組範圍 / Public module scope

## 中文版

核心模組為討論、會議、決議、任務、證據、Agent、Role、Skill、Model Connector 與 MCP Connector。Reference Task Adapter 是參考實作；Goal Run、OMP、Harness 與 ACS 為預設關閉的實驗功能。公開預覽不依賴任何特定 Tailnet、私人 SSH 主機或主機閘道綁定。

## English version

Core modules cover discussions, meetings, decisions, tasks, evidence, Agents, Roles, Skills, model connectors, and MCP connectors. The Reference Task Adapter is an example implementation. Goal Run, OMP, Harness, and ACS are disabled-by-default experiments. The public preview has no dependency on a particular Tailnet, private SSH host, or host gateway binding.
