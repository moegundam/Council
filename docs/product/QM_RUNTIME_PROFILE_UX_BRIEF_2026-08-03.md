# Runtime Profile 介面摘要 / Runtime Profile UX brief

## 中文版

Owner 只能選擇已核准、可用且符合任務作用域的 Runtime Profile。介面須顯示隔離方式、image digest、工具與網路限制；未滿足條件時保持關閉並指出缺少設定。

## English version

Owners may select only approved, available Runtime Profiles that fit the task scope. The interface shows isolation, image digest, tool, and network limits. An incomplete profile remains disabled and names the missing configuration.
