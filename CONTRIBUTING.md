# 貢獻指南 / Contributing

## 中文版

請先開 issue 說明問題、重現方式與預期結果。變更應保持安全預設、補上能驗證行為的測試，並通過 `pnpm verify`。提交即表示你有權貢獻該內容，並同意以 `AGPL-3.0-only` 授權；第三方程式或素材必須同時附上來源、版本及授權。請勿提交真實憑證、私人會議資料、日誌、附件或內部基礎設施設定。

小型提交請保持單一目的。行為變更須更新中英文文件；安全問題請依 [SECURITY.md](SECURITY.md) 私下回報，不要先開公開 issue。首版不要求額外 CLA。

## English version

Open an issue with the problem, reproduction steps, and expected behavior. Keep secure defaults, add tests that verify behavior, and run `pnpm verify`. By contributing, you confirm that you have the right to submit the material under `AGPL-3.0-only`. Include source, version, and license details for all third-party code or assets. Never commit real credentials, private meeting data, logs, attachments, or internal infrastructure configuration.

Keep small changes focused and update both language sections when behavior changes. Report security issues privately through [SECURITY.md](SECURITY.md). No additional CLA is required for this preview.
